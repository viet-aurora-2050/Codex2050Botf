# Public-source expansion prompt

Inspect the aggregator and identify legitimate public machine-readable game catalogues or official/provider feeds suitable for automated retrieval.

For each candidate: verify public accessibility/automation terms, document schema/rate limits/freshness, create a dedicated adapter and fixture tests, retain provenance, and make it independently revertible.

Do not scrape authenticated casino sessions, infer private endpoints, bypass protections, or treat recent wins as predictive. If no trustworthy source exists, do not fabricate one; document the adapter interface and any licensing/API requirement instead.
